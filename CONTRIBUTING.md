# Contributing

Thanks for helping improve MyAttendo.

1. Open an issue before large changes.
2. Fork and create a focused feature branch.
3. Keep student and institutional data synthetic in development.
4. Add tests for changed behaviour.
5. Never commit credentials, tokens, private portal data or real student records.
6. Submit a pull request with a clear summary and test steps.

Potential contributions: accessibility, automated tests, timetable administration, audit history, university SSO adapters (only against approved test systems), import validation, translations and deployment documentation.
